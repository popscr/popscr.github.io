PopScript

A simple programming language.

A statically typed interpreted language focused on readable syntax and simple programming.

View on GitHub See example

Features

Static typing

Explicit types such as int, float, string, bool and list.

Readable syntax

Simple syntax designed to be easy to understand.

String interpolation

Put variables directly inside strings with {name}.

GUI support

Build desktop interfaces using the built-in ui library.

Functions

Functions support parameters, return values and scopes.

Memory control

Optional manual memory management with armemory.

Example

A small PopScript program using the random library.

example.pscript 
$/ PopScript 1.0.4 example program
lib import random
lib import random.number

int min_val = 0
int max_val = 100

int x = number(from=min_val, to=max_val)
int y = x + 5

if x > 50;
    print(x)
    print("high value")
stop;

if x <= 50;
    print(x)
    print("low value")
stop;
